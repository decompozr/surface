The vendor archive is the real packaged design system at the accompanying identity pin, not a copied or reimplemented UI. It keeps the mounted source self-contained under Surface's filesystem rules. When adopting a provider revision, regenerate the package archive and source lock, verify these pages, and update the pin together.

The vendor archive and frozen lock must match the provider identity used by the shell.
