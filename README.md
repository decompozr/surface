# Surface

An experiment in bringing AI-created knowledge and tools out of the chat.

Bring documents, visualizations and small tools out of the chat, then send page feedback to the same agent conversation that has the context.

- Provider-independent architecture with explicit conversation binding.
- Git-versioned page source and separate identities for multiple worktrees.
- Element selection, screenshots, comments and agent replies.
- Optional private access across devices with Tailscale.

## Getting started

Follow the [setup guide](SETUP.md), then use the [Surface skill](skills/surface/SKILL.md) to create and mount a page.

Surface currently hosts trusted, project-owned Svelte pages. It is a hobby experiment; a general persistent document editor is still a future direction.
